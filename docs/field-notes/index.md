## What a Field Note is

Every issue follows the same anatomy. The cadence and the structure are the contract:

- **Dek** -- one sentence stating the claim
- **Opening** -- two paragraphs anchored in primary sources
- **The pattern** -- the mechanic, not the marketing
- **Where it fails** -- the tradeoff, explicit
- **In code** -- a link to the working file in the repo
- **Sources** -- numbered, with URLs

No filler. No listicles. No "5 things you should know about X." If a claim cannot be cited or reproduced, it does not ship.
